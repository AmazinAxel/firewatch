# Firewatch for the esp32: sds011 and trmnl

A fire tracking solution for the sds011 (hooked up to an esp32-c3 super mini and plugged into a battery with a solar cell) and the TRMNL for displaying the data on a non-distracting e-ink display!

Firescreen is for the trmnl's esp32, firetracker is for the sds011's esp32.
